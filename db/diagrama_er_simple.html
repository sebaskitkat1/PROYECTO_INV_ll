Diagrama entidad-relación comprimido · frutidata

14 tablas esenciales, solo nombres y relaciones. Sin atributos, llaves ni tipos de dato. Cinco módulos para explicar el flujo general y la ruta de la predicción.

||--o{ uno a muchos ||--|{ uno a uno o más Las tablas puente resuelven los muchos-a-muchos.

1. Catálogo y ventas

Productos, sucursales, ventas y renglones de venta.

erDiagram
    SUCURSALES ||--o{ VENTAS : "opera"
    VENTAS ||--|{ DETALLE_VENTAS : "contiene"
    PRODUCTOS ||--o{ DETALLE_VENTAS : "se vende"

2. Recetas

Un producto vendible consume ingredientes; la receta guarda la cantidad.

erDiagram
    PRODUCTOS ||--o{ RECETAS : "compone"
    INGREDIENTES ||--o{ RECETAS : "ingrediente"

3. Inventario

Saldo por sucursal, lotes con caducidad y kardex de movimientos.

erDiagram
    SUCURSALES ||--o{ INVENTARIO : "almacena"
    INGREDIENTES ||--o{ INVENTARIO : "stock"
    SUCURSALES ||--o{ LOTES_INVENTARIO : "lotes"
    INGREDIENTES ||--o{ LOTES_INVENTARIO : "lote"
    SUCURSALES ||--o{ MOVIMIENTOS_INVENTARIO : "mueve"
    INGREDIENTES ||--o{ MOVIMIENTOS_INVENTARIO : "mueve"
    VENTAS ||--o{ MOVIMIENTOS_INVENTARIO : "descuenta"

4. Compras

Cabecera de orden, detalle por ingrediente y entrada al inventario.

erDiagram
    SUCURSALES ||--o{ ORDENES_COMPRA : "solicita"
    ORDENES_COMPRA ||--|{ DETALLE_ORDENES_COMPRA : "detalla"
    INGREDIENTES ||--o{ DETALLE_ORDENES_COMPRA : "pide"
    ORDENES_COMPRA ||--o{ MOVIMIENTOS_INVENTARIO : "ingresa"

5. Pronóstico

Corrida, serie diaria y detalle por producto.

erDiagram
    SUCURSALES ||--o{ PRONOSTICOS : "genera"
    PRONOSTICOS ||--o{ PRONOSTICO_DIARIO : "serie diaria"
    PRONOSTICOS ||--o{ PRONOSTICO_PRODUCTO : "detalle"
    PRODUCTOS ||--o{ PRONOSTICO_PRODUCTO : "producto"
Ruta de la predicción: VENTAS + DETALLE_VENTAS → serie diaria de unidades → PRONOSTICOS → PRONOSTICO_DIARIO / PRONOSTICO_PRODUCTO. PRODUCTOS aporta precio, costo y vida de anaquel. INVENTARIO y LOTES_INVENTARIO se usan para el pedido y la caducidad.
