COSECHA - INSTALACION

1. Abre "Configurar base de datos" en el menu Inicio y edita .env:
   DB_HOST, DB_PORT, DB_USER, DB_PASSWORD y DB_NAME.
   Opcional: DB_SSL=1 exige TLS y DB_POOL_SIZE ajusta el pool (4 por defecto).
   Usa DB_USER=cosecha_app (nunca root) y la misma contrasena que pusiste
   en db\crear_usuario_app.sql.
   Si no configuras MySQL, la app abre en modo ejemplo y no guarda cambios.

2. Primera instalacion de la base, como root:
   mysql -u root -p < "%LOCALAPPDATA%\Programs\Cosecha\db\init_schema.sql"

   Luego aplica las migraciones en este orden, tambien como root:
   mysql -u root -p < "%LOCALAPPDATA%\Programs\Cosecha\db\migrate_ordenes_pendientes.sql"
   mysql -u root -p < "%LOCALAPPDATA%\Programs\Cosecha\db\migrate_catalogo_pos.sql"
   mysql -u root -p < "%LOCALAPPDATA%\Programs\Cosecha\db\migrate_fix_totales_ventas.sql"
   mysql -u root -p < "%LOCALAPPDATA%\Programs\Cosecha\db\migrate_cantidades_decimales.sql"
   mysql -u root -p < "%LOCALAPPDATA%\Programs\Cosecha\db\migrate_inventario_recetas.sql"
   mysql -u root -p < "%LOCALAPPDATA%\Programs\Cosecha\db\migrate_kpi_precio_unidad.sql"
   mysql -u root -p < "%LOCALAPPDATA%\Programs\Cosecha\db\migrate_fase0.sql"
   mysql -u root -p < "%LOCALAPPDATA%\Programs\Cosecha\db\migrate_fase2.sql"
   mysql -u root -p < "%LOCALAPPDATA%\Programs\Cosecha\db\migrate_fase5.sql"

   Cada migracion se registra en la tabla schema_migrations.

3. Crea el usuario de la aplicacion con permisos minimos, como root:
   mysql -u root -p < "%LOCALAPPDATA%\Programs\Cosecha\db\crear_usuario_app.sql"
   Antes de ejecutarlo, cambia CAMBIAR_CONTRASENA_SEGURA por una contrasena
   propia y usa el mismo valor en DB_PASSWORD.

   Si la base ya existe, salta el paso 2 del schema y aplica solo las
   migraciones pendientes; el paso 3 tambien es necesario.

4. Los usuarios de la base deben tener contrasena bcrypt. La app rechaza
   contrasenas en claro o hashes de otro formato.

5. Abre Cosecha desde el menu Inicio. El estado de la esquina indica si esta
   usando la base o el ejemplo.

6. Haz respaldo de MySQL antes de actualizar esquema o recibir ordenes de
   compra. La recepcion de una orden descuenta inventario y registra kardex.

  db\init_schema.sql    Crea la base si no existe; no borra datos
  db\crear_usuario_app.sql  Usuario cosecha_app con permisos minimos
  db\migrate_ordenes_pendientes.sql
  db\migrate_catalogo_pos.sql
  db\migrate_fix_totales_ventas.sql
  db\migrate_cantidades_decimales.sql
  db\migrate_inventario_recetas.sql
  db\migrate_kpi_precio_unidad.sql
  db\migrate_fase0.sql
  db\migrate_fase2.sql
  db\migrate_fase5.sql
  README.md

Solo se usa en desarrollo.
